Processing & Features

Engineered vegetation indices and spectral reflectance features

Signal Preprocessing & Feature Extraction Pipeline

Raw sensor curves pass through Savitzky-Golay filtering (window length: 11, polynomial order: 2) to eliminate high-frequency electronic noise without attenuating critical physiological inflection points (such as the red edge). Next, 14 calibrated physiological features are computed:

NDVI / GNDVI: Canopy vigor & nitrogen index
NDRE: Red-edge chlorophyll sensitivity
WBI (900/970nm): Cellular water status
VIS & NIR Means: Broadband reflection ratios
