    System Overview

    This system performs plant-specific multispectral stress classification using spectral measurements, engineered spectral features, and machine-learning models. Measurements can be stored over time for plant-wise history and progress tracking.

    Plant Selection → Plant ID → Leaf Measurement → Spectral Data Acquisition → Quality Check → Preprocessing → Spectral Feature Extraction → Plant-Specific ML Model → Stress Classification → Model Confidence → Plant-Specific Interpretation → Recommendation → Report Generation → History & Progress Tracking
    • Multispectral spectral analysis
    • Plant-specific machine-learning classification
    • Model confidence and model-level explainability
    • Measurement history and plant-wise timeline
    • Individual diagnosis reports & Plant Health Progress Reports

    Sensor Profile Information

    CURRENT RESEARCH MODEL: VIS-NIR Research Spectrometer (832 bands)
    Research dataset representation (~395–1021 nm, 832 samples). Used by current Tomato research model.

    PLANNED PHYSICAL SENSOR: AS7341
    Low-cost multispectral sensor intended for the physical prototype. It does NOT directly produce the current 832-band input. A validated AS7341-specific preprocessing/model pipeline is required.

    Clear measurement history?

    This will permanently remove stored measurement records for the current plant, including its timeline and progress-report data. ML models, plant profiles, and application configuration will not be affected.
